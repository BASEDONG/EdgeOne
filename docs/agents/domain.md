# Domain Docs

EdgeOne uses a multi-context layout. Read the root `GLOSSARY-MAP.md` to locate the contexts relevant to the task.

- Read each relevant context's `GLOSSARY.md`.
- Check root `docs/adr/` for decisions that apply across contexts.
- Check `docs/adr/` under each relevant context root for local decisions.

Proceed when a glossary or ADR directory is absent. Create glossaries and ADRs as terms and decisions are settled. Add each established context to `GLOSSARY-MAP.md` using its actual path.

Use glossary terms in issues, proposals, and tests. If a proposal conflicts with an ADR, cite the ADR and explain why the decision should be reopened.
